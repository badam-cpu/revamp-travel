# Revamp Travel Website Brand System

The attached Revamp brandbook is the ground-truth visual specification for the marketplace. The website preserves its Armenian travel content and product functionality while following the formal Revamp identity throughout the interface and brand presentation.

| System area | Website implementation |
| --- | --- |
| Primary logo | Use the intact lowercase **`revamp.`** wordmark with a terminal period. No uppercase, stacked, outlined, shadowed, multi-color, or split variants. Maintain generous clear space equal to approximately the wordmark’s cap-height around the mark. |
| Compact mark | Use **`re.`** in a rounded-square container for favicon and small branded controls. Approved colorways are white on #F15822, white on #212121, or dark on white with a thin dark keyline. |
| Core palette | Brand orange **#F15822**, charcoal **#212121**, and white **#FFFFFF**. Supporting surfaces may use only controlled 90%, 70%, 50%, and 30% tints of orange or charcoal. Existing teal, rose, cream, pomegranate, and decorative atlas colors will be removed from interface branding. |
| Typography | Use a Circular Std–like geometric sans system throughout. Because the proprietary font file is not supplied for licensed web embedding, **Manrope** will serve as the web-safe visual substitute, with `Circular Std` first in the fallback stack for environments where it is available. Serif display typography will be removed. |
| Decorative typography | Cartesian is reserved for rare accent treatment only. The marketplace will avoid relying on it because no licensed webfont file is supplied. |
| Shape language | Use rounded squares and rounded rectangles with consistent radii, echoing the approved icon and merchandise containers. Remove carved corners and ornamental atlas frames from branded UI. |
| Graphic pattern | Use oversized cropped fragments of `re.` or `revamp.` as low-contrast section patterns on orange or dark surfaces. Pattern use should be sparse, large-scale, and flat—never a dense repeated wallpaper. |
| Photography | Keep Armenia-specific landscape, architecture, food, and local experience imagery. Photographs remain the cultural layer, while UI framing and overlays use only approved brand colors. |
| Buttons and controls | Primary actions use brand orange with white text. Secondary actions use charcoal or white/charcoal outlines. Controls adopt rounded-rectangle geometry, clear labels, and Circular-like typography. |
| Maps and categories | Preserve interactivity, but recolor markers and atlas details to orange, charcoal, white, and approved tints. Category differentiation relies on icons and labels rather than non-brand colors. |

The resulting experience should feel **bold, clean, contemporary, practical, and recognizably Revamp**. Armenia remains unmistakable through content and imagery; the interface itself becomes simpler, brighter, more geometric, and tightly governed by the brandbook.
